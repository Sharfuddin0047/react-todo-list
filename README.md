# 🔁 Jenkins CI/CD Pipeline

This project uses a **Jenkins Declarative Pipeline** to automate the build and deployment process.

The pipeline performs the following tasks:

1. Clone the source code from GitHub
2. Build a Docker image with the application
3. Push the Docker image to **AWS ECR**
4. Push the same image to **DockerHub**
5. Deploy the new image to **AWS ECS**

---

# 📊 CI/CD Workflow

```
Developer
   │
   ▼
GitHub Repository
   │
   ▼
Jenkins Pipeline
   │
   ├── Code Checkout
   ├── Docker Build
   ├── Push Image → AWS ECR
   ├── Push Image → DockerHub
   └── Deploy → AWS ECS
           │
           ▼
     Running Container on ECS
```

---

# ⚙️ Pipeline Environment Variables

The Jenkins pipeline uses several environment variables to configure the deployment process.

| Variable               | Description                                   |
| ---------------------- | --------------------------------------------- |
| `DOCKER_USER`          | DockerHub username                            |
| `IMAGE_NAME`           | Docker image name                             |
| `AWS_DOCKER_REGISTRY`  | AWS ECR registry URL                          |
| `BUILD_TAG`            | Unique build number generated by Jenkins      |
| `AWS_DEFAULT_REGION`   | AWS region where ECS/ECR are deployed         |
| `AWS_ECS_CLUSTER`      | ECS cluster name                              |
| `AWS_ECS_SERVICE_PROD` | ECS service name                              |
| `AWS_ECS_TD_PROD`      | ECS task definition name                      |
| `MOCK_API_URL`         | MockAPI endpoint stored as Jenkins credential |

# 📦 Pipeline Stages

## 1️⃣ Code Checkout

Jenkins pulls the source code from the GitHub repository.

```groovy
stage('Code Checkout')
```

Repository used:

```
https://github.com/Sharfuddin0047/react-todo-list
```

---

# 🐳 2️⃣ Build Docker Image

The application is containerized using Docker.

The pipeline builds the image and injects the **MockAPI URL as a build argument**.

```bash
docker build -t $IMAGE_NAME:$BUILD_TAG \
--build-arg VITE_MOCKAPI_BASE_URL=$MOCK_API_URL .
```

This allows the frontend to dynamically use the API endpoint.

---

# ☁️ 3️⃣ Push Image to AWS ECR

The pipeline authenticates with AWS and pushes the Docker image to **Amazon Elastic Container Registry**.

Steps performed:

1. Tag the Docker image
2. Authenticate with ECR
3. Push image to ECR repository

Example:

```bash
docker tag $IMAGE_NAME:$BUILD_TAG $AWS_DOCKER_REGISTRY/$IMAGE_NAME:$BUILD_TAG
docker push $AWS_DOCKER_REGISTRY/$IMAGE_NAME:$BUILD_TAG
```

---

# 🐳 4️⃣ Push Image to DockerHub

The pipeline also publishes the image to **DockerHub** for easier access and backup.

Steps:

1. Login to DockerHub
2. Tag the image
3. Push version tag
4. Push `latest` tag

Example:

```bash
docker push ${DOCKER_USERNAME}/${IMAGE_NAME}:${BUILD_TAG}
docker push ${DOCKER_USERNAME}/${IMAGE_NAME}:latest
```

---

# 🚀 5️⃣ Deploy to AWS ECS

Deployment is performed using **AWS CLI inside a Docker container**.

The pipeline:

1. Updates the ECS **task definition**
2. Replaces the image version with the latest build tag
3. Registers a new task revision
4. Updates the ECS service
5. Waits until the service becomes stable

Example process:

```
Update Task Definition
        │
Register New Revision
        │
Update ECS Service
        │
Wait Until Deployment Stable
```

Command used:

```bash
aws ecs update-service \
--cluster $AWS_ECS_CLUSTER \
--service $AWS_ECS_SERVICE_PROD \
--task-definition $AWS_ECS_TD_PROD:$LATEST_TD_REVISION
```

# 🔐 Jenkins Credentials Used

The pipeline securely retrieves sensitive values using **Jenkins Credentials Manager**.

| Credential ID  | Purpose                   |
| -------------- | ------------------------- |
| `my-aws`       | AWS access key and secret |
| `dockerPAT`    | DockerHub authentication  |
| `mock-api-url` | MockAPI endpoint          |

# 🧹 Workspace Cleanup

After pipeline execution, Jenkins automatically cleans the workspace:

```groovy
post {
    cleanup {
        cleanWs()
    }
}
```

This ensures each build starts with a **fresh environment**.
